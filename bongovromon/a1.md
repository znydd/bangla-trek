# Member-1 — UI Feature Descriptions (According to Requirement Analysis)

---

## Feature 1: Community Data Contribution (Module 1, Requirement 1)

### Description

This feature allows travelers and locals to contribute location data for attractions, hotels, guesthouses, homestays, and restaurants through the BongoVromon platform. Users provide key details including the place's name, location, price range, amenities, photos, and travel tips. To reduce server costs while maintaining a highly visual experience, users can embed URLs from popular travel vloggers' reels on YouTube, Facebook, and TikTok directly into location pages, alongside uploading their own photos via the Cloudinary API. The system automatically categorizes contributed entries with "Hidden Gem" or "Trending" tags to help future travelers discover both viral and underrated spots across Bangladesh.

### Key Functional Requirements

- Users can submit data for five location categories: attractions, hotels, guesthouses, homestays, and restaurants.
- Each submission captures: name, location, price range, amenities, photos, and travel tips.
- Photo uploads are handled through the Cloudinary API.
- Users can embed external video URLs (YouTube/Facebook/TikTok reels) from travel vloggers into location pages.
- The system tags entries as "Hidden Gem" or "Trending" to highlight viral and underrated destinations.

### UI Elements Required

- Category selector (attraction, hotel, guesthouse, homestay, restaurant)
- Details form (name, location picker, price range, amenities, tips)
- Photo upload area (drag-and-drop, Cloudinary-powered)
- Video URL embed field with preview
- "Hidden Gem" / "Trending" tag toggle
- Live listing preview card

## Feature 2: Group Trip Creation (Module 2, Requirement 1)

### Description

This feature enables users to create public or private group trips, invite others via shareable links, and discover fellow travelers planning to visit the same destination during overlapping dates. The goal is to facilitate coordination for potential meetups and shared travel experiences. Users can set their trip as public (visible to the community for discoverability) or private (accessible only via invite link), making it flexible for both open travel groups and personal friend circles.

### Key Functional Requirements

- Users can create group trips with destination, travel dates, and visibility setting (public or private).
- The system generates shareable invite links for each group trip.
- Users can see other travelers planning to visit the same destination during overlapping dates.
- The platform supports coordination for potential meetups and shared experiences among overlapping travelers.

### UI Elements Required

- Group trip creation form (trip name, destination, date range, public/private toggle, description)
- Shareable invite link generator with copy-to-clipboard functionality
- Overlapping traveler discovery panel (shows users with matching destination and dates)
- Existing group trips list view
- Meetup request interaction
