# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Bangla Trek — Smart Travel Itinerary Planner for Bangladesh. Monorepo with a FastAPI backend and a Vite/React frontend.

## Commands

### Backend (`backend/`)
```bash
uv run fastapi dev app/main.py          # dev server on :8000
uv run alembic revision --autogenerate -m "description"  # generate migration
uv run alembic upgrade head             # apply migrations
uv run alembic downgrade -1             # rollback one
```

### Frontend (`frontend/`)
```bash
npm run dev          # dev server on :5173
npm run build        # production build
npm run routes:generate  # manually regenerate routeTree.gen.ts (auto-runs on dev)
```

### Infrastructure
```bash
docker compose up -d   # start PostgreSQL 17 on :5432
```

## Architecture

### Backend

- **Framework**: FastAPI with synchronous SQLAlchemy (not async despite the asyncio dependency being present)
- **Entry**: `app/main.py` → mounts `app/api/v1/router.py`
- **Config**: `app/config.py` — pydantic-settings reads from `backend/.env`
- **DB**: `app/db/session.py` — sync `SessionLocal`, injected via `Depends(get_db)`
- **Auth flow**: Google OAuth 2.0 → backend exchanges code → sets two httpOnly cookies (`access_token` path `/`, `refresh_token` path `/api/v1/auth/refresh`) → redirects to `${FRONTEND_URL}/auth/callback`
- **Auth dependencies** (`app/api/deps.py`):
  - `get_current_user_id` — JWT decode only, no DB hit, use on all protected routes
  - `get_current_user` — JWT + DB query, use only when you need the full User object
- **Migrations**: Alembic with `autogenerate`. All models must be imported in `alembic/env.py` for autogenerate to detect them. When adding a new model, add it to `app/models/__init__.py` AND `alembic/env.py`.

### Frontend

- **Router**: TanStack Router v1 with file-based routing. `routeTree.gen.ts` is auto-generated by the Vite plugin on `npm run dev` — do not edit it manually.
- **Auth guard**: `routes/authenticated.tsx` uses `beforeLoad` with `ensureQueryData(currentUserQueryOptions)` — redirects to `/` if the cookie is invalid/missing.
- **API client**: `src/lib/api.ts` — Axios with `withCredentials: true`. Interceptor catches 401, attempts `POST /api/v1/auth/refresh`, retries once, then redirects to `/` on failure.
- **No token storage in JS** — tokens live exclusively in httpOnly cookies. The Axios client never reads or writes tokens.
- **Path alias**: `@/` maps to `src/`.
- **Env**: `frontend/.env` — only `VITE_API_URL` (the only variable exposed to the browser bundle).

### Auth flow end-to-end
```
/ (home)
  → click Login → GET /api/v1/auth/google → 307 to Google
  → Google → GET /api/v1/auth/callback?code=... → sets cookies → 307 to /auth/callback (frontend)
  → /auth/callback → navigate to /authenticated
  → /authenticated beforeLoad → ensureQueryData → GET /api/v1/auth/me (single call)
  → render page

logout
  → POST /api/v1/auth/logout → queryClient.clear() → window.location.href = "/"
```

## Key conventions

- New API routers go in `app/api/v1/`, registered in `app/api/v1/router.py`.
- Use `get_current_user_id` (not `get_current_user`) on new protected endpoints unless you need the User ORM object.
- JWT secret must be ≥ 32 bytes or PyJWT will warn.
- `VITE_` prefix is required for any env var that needs to be accessible in frontend code.
